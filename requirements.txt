# >= instead of == on the three below: each was pinned to an exact old
# version that predates prebuilt wheels for newer Python releases (e.g.
# rapidfuzz==3.9.7 and Pillow==10.4.0 have no Python 3.14 wheel, and
# psycopg2-binary==2.9.10 has no Python 3.14 wheel either - support was
# added in 2.9.11). An exact old pin forces pip to compile from C source
# on any newer interpreter, which fails without a full build toolchain
# (and, for psycopg2, without PostgreSQL's pg_config on PATH). A floor
# instead of a pin lets pip pick the newest compatible wheel automatically.
